PrettyLog Sample
=================

This sample shows how to use the `PrettyLog` static API from a scene.

Usage
-----
1. Open the package in Unity (local package path or via Package Manager).
2. In the Project window, navigate to `Packages/com.acproject.prettylog/Samples~/PrettyLogSample`.
3. Drag `PrettyLogSampleUsage` onto a GameObject in your scene.
4. Enter Play mode to see sample logs in the Console.

Files
-----
- `Runtime/SampleUsage.cs` — example MonoBehaviour demonstrating `Log`, `LogWarning`, and `LogError`.
